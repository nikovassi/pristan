# Пристан — сайт за психологическо консултиране

Малък, спокоен и бърз сайт за индивидуална психологическа практика.
React + TypeScript + Vite + Tailwind CSS, публикуван автоматично в GitHub Pages.

> Всички професионални данни (име, квалификация, цени, адрес, телефон) са **placeholder-и**.
> Сменете ги, преди сайтът да бъде показван на клиенти.

---

## Бързи промени — всичко е в `src/config/site.ts`

| Какво | Къде в `site.ts` |
|---|---|
| **Booking URL** | `BOOKING_URL = '…'` — всички бутони за записване го използват |
| Booking доставчик (текст в политиките) | `BOOKING_PROVIDER` |
| **Име на практиката**, tagline | `site.brand` |
| **Име, квалификация, образование, сертификати, опит, подход** | `site.psychologist` |
| **Снимка** | `site.psychologist.photo` — сложете файла в `public/images/` и задайте `'/images/portrait.jpg'` (препоръчително 800×1000 px, JPG/WebP) |
| **Телефон, имейл, адрес** | `site.contact` (`phone` е за показване, `phoneHref` — без интервали) |
| **Работно време** | `site.contact.hours` |
| **Цени и видове консултации** | `site.services` — `price`, `duration`, `description`; `site.currency` |
| Директен линк към конкретна услуга | `site.services[i].bookingUrl` (по избор) |
| Начини на плащане, отмяна | `site.payment` |
| Социални мрежи | `site.social` |
| Статистика (изключена) | `site.analytics` |

След промяна: `git commit` + `git push` → сайтът се обновява автоматично за ~1–2 минути.

### Други текстове

- **Теми „С какво мога да помогна“, стъпки „Как протича“, ценности, FAQ** → `src/content/home.ts`
- **Отзиви** → `testimonials` в `src/content/home.ts`. Секцията се показва автоматично, когато масивът не е празен. Добавяйте **само реални отзиви с писмено разрешение**.
- **Текст „За мен“ и hero** → `src/pages/Home.tsx` и `src/components/Hero.tsx`
- **Правни текстове** → `src/content/legal.ts` (шаблони — прегледайте със специалист)

### Добавяне на статия

Отворете `src/content/articles.ts` и добавете нов обект:

```ts
{
  slug: 'moyata-nova-statiya',          // адрес: /polezno/moyata-nova-statiya
  title: 'Заглавие',
  description: 'Едно-две изречения за търсачките и картата на статията.',
  date: '2026-10-15',
  minutes: 4,
  body: `
Първи абзац.

## Подзаглавие

- елемент от списък
- още един
`,
},
```

Статията получава собствена страница, влиза в списъка „Полезно“ и в `sitemap.xml`.

## Онлайн записване — Cal.com

Сайтът **не съхранява** клиентски данни. Записването се извършва в Cal.com (безплатен план за един специалист).
Календарът е вграден в страницата „Запази час“ и се зарежда едва след като посетителят избере вид консултация.

1. **Settings → Security**: включете двуфакторна автентикация.
2. **Settings → Calendars**: свържете Google Calendar. Заетите часове там се блокират автоматично, а новите записвания се появяват в календара.
3. **Availability**: работно време, почивни дни, изключения за конкретни дати.
4. **Event types**: по един тип за всяка консултация в `site.services`, всички **60 минути**. Препоръчани настройки:
   - *Limits*: минимално предизвестие (напр. 12 ч.), буфер 10 мин след среща;
   - *Location*: адрес на кабинета или Cal Video / Google Meet за онлайн;
   - *Booking questions*: само Име, Имейл, Телефон. Ако оставите „Additional notes“, напишете в описанието му:
     *„Моля, не въвеждайте чувствителна медицинска информация в полето за съобщение.“*
5. **Workflows**: напомняне по имейл 24 ч. преди срещата.
6. Отмяна и пренасрочване са включени по подразбиране — клиентът получава линкове в имейла за потвърждение.
7. Поставете **публичния** линк (напр. `https://cal.com/потребител`) в `BOOKING_URL`, а линковете на отделните типове (`https://cal.com/потребител/parva`) — в `site.services[i].bookingUrl`.

> `app.cal.com` съхранява данните в САЩ (EU-US Data Privacy Framework). За данни в ЕС използвайте акаунт в `cal.eu`
> и сменете `BOOKING_PROVIDER.dataLocation`.

Докато `BOOKING_URL` не е зададен, страницата „Запази час“ показва телефон и имейл вместо календар — нито един бутон не е без функция.

## Поверителност — какво е заложено

- Няма контактни форми, няма Google Analytics, Facebook Pixel или други trackers.
- Шрифтовете се хостват локално (без Google Fonts).
- Календарът на Cal.com се зарежда само след избор на консултация (без чужди скриптове преди това).
- `localStorage` пази само избраната тема.
- Ако включите `site.analytics`, се показва банер за съгласие и скриптът се зарежда едва след „Разреши“.
- В репото **не се пазят** пароли, API ключове, клиентски данни, бележки или диагнози.

## Разработка

```bash
npm install
npm run dev        # локален сървър
npm run build      # проверка на типове + build + prerender + sitemap
```

## Публикуване (GitHub Pages)

`.github/workflows/deploy.yml` build-ва и публикува при всеки push в `main`.
Еднократно: **Settings → Pages → Source: GitHub Actions**.

### Собствен домейн

1. Settings → Pages → Custom domain: `www.вашдомейн.bg`; включете **Enforce HTTPS**.
2. Settings → Secrets and variables → Actions → **Variables** → `CUSTOM_DOMAIN = www.вашдомейн.bg`.
3. При DNS доставчика: `CNAME www → <user>.github.io`.

Пътищата, canonical адресите и sitemap се настройват автоматично.
